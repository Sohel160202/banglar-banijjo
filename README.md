# বাংলার বাণিজ্য

বাংলাদেশের শহর, সম্পত্তি, ব্যবসা, রাজনীতি ও অর্থনীতিকে ঘিরে একটি অনলাইন কৌশলভিত্তিক বোর্ড গেম।

## বর্তমান অবস্থা

প্রথম উৎপাদন-প্রস্তুত নকশা-স্লাইস তৈরি হয়েছে:

- সম্পূর্ণ বাংলা ব্যবহারকারী অভিজ্ঞতা
- প্রিমিয়াম ড্যাশবোর্ড
- বাংলাদেশের শহরভিত্তিক মানচিত্রের প্রিভিউ
- বাজারের পরিসংখ্যান
- সম্পত্তি ও ব্যবসার ধারণা
- বিশেষ অর্থনৈতিক ঘটনা
- মোবাইল ও ডেস্কটপ উপযোগী নকশা

## পরবর্তী ধাপ

1. Supabase Authentication
2. খেলার ঘর তৈরি ও যোগদান
3. Realtime multiplayer state
4. server-authoritative dice, money, ownership and turns
5. প্রথম বাংলাদেশের বোর্ডের সম্পূর্ণ নিয়ম
6. Vercel production deployment

## উন্নয়ন নীতি

ব্যবহারকারীর সামনে দৃশ্যমান সব লেখা বাংলায় থাকবে। কোড, ডাটাবেস কলাম এবং অভ্যন্তরীণ প্রযুক্তিগত নাম ইংরেজিতে রাখা হবে যাতে রক্ষণাবেক্ষণ ও নিরাপত্তা নির্ভরযোগ্য থাকে.
